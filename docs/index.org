* The welkomscherm manual

/welkomscherm/ is Dutch for *welcome screen*.  This is the manual for
welkomscherm.el, a small, calm, extensible welcome screen for Emacs 28.1 and
newer, built from nothing but Emacs itself.

The [[file:../README.org][README]] is the front page: what the package is for, a picture of it, and
the shortest install.  These pages are the rest.

** The thirty-second tour
:PROPERTIES:
:CUSTOM_ID: the-thirty-second-tour
:END:

1. Put welkomscherm on your ~load-path~ and require it, or install it the way
   [[file:installation.org][Installation]] describes.
2. Point it at a directory or file you open all day:

   #+begin_src emacs-lisp
     (require 'welkomscherm)
     (setq welkomscherm/bookmarks-list
           '((("org" . "~/org/") ("notes" . "~/notes.org"))))
   #+end_src

3. Run ~M-x welkomscherm~.

To make it the first thing you see, set ~initial-buffer-choice~ as
[[file:installation.org::#welkomscherm-at-startup][Welkomscherm at startup]] shows.
